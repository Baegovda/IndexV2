# Suckdex

Saber Interactive 게임 속을 열어, 텍스처와 모델을 꺼내 쓰는 Windows 도구입니다.

![Suckdex에서 게임을 연 화면](https://user-images.githubusercontent.com/13636711/209453493-8ea09492-2493-43c8-a16e-5f7f392f863f.png)

설치 폴더를 지정하면 게임을 찾습니다. 파일을 고르고, 미리 본 다음, 작업에 쓸 형식으로 저장할 수 있습니다.

## 지원하는 게임

- **Halo: Combat Evolved Anniversary**
- **Halo 2: Anniversary**
- **Warhammer 40,000: Space Marine 2**

## 꺼내 쓸 수 있는 것

텍스처는 크게 보고 PNG, DDS, TGA, JPEG로 저장합니다.

모델은 뷰포트에서 돌려 보고 FBX, glTF 2, COLLADA, STL로 저장합니다.

텍스트를 읽을 수 있고, 고른 파일을 한꺼번에 내보낼 수 있습니다.

## 실행

Windows와 [.NET 8 데스크톱 런타임](https://dotnet.microsoft.com/download/dotnet/8.0)이 필요합니다. 앱을 연 뒤 게임이 설치된 폴더를 지정하면 됩니다.

Suckdex는 [Haus](https://github.com/Wildenhaus)의 Index를 여러 게임이 열리도록 다시 만든 프로그램입니다.

## 업데이트

프로그램이 바뀔 때마다 이 목록의 맨 위를 고칩니다.

- 1.1.4.0: 데이터 탐색기에서 자산을 우클릭하면 즐겨찾기에 넣거나 뺄 수 있다.
- 1.1.3.0: 데이터 탐색기와 즐겨찾기에서 위아래 방향키로 선택을 옮기면 그 파일이 열린다.
- 1.1.2.0: 열린 파일 탭에서 휠 버튼을 누른 채로 있으면 탭이 계속 닫힌다. 짧게 누르면 하나만 닫힌다.
- 1.1.1.0: 데이터 탐색기와 즐겨찾기에서 파일 이름을 한 번 누르면 열린다.
- 1.1.0.0: 데이터 탐색기에 즐겨찾기 칸이 생겼다. 자산을 우클릭해 넣고, 목록에서 연다. 넣은 목록은 게임을 다시 열어도 남는다.
- 1.0.1.0: 최근 검색어가 검색창 아래에 바로 보인다.
- 1.0.0.1: 빌드와 문제 목록에 나오던 기존 경고를 숨겼다.
- 1.0.0.0: 프로그램과 프로젝트 이름을 Suckdex로 바꿨다. 실행 파일은 Suckdex.exe다.
- 0.5.7.0: 모델 화면의 VOL 목록도 접혀 있다.
- 0.5.6.0: 최근 검색어가 알약 모양으로 보이고, ×로 지울 수 있다.
- 0.5.5.0: 모델 화면의 LOD 목록은 접혀 있다.
- 0.5.4.0: 런처에 게임 썸네일이 보인다.
- 0.5.3.0: 검색어 기록이 남는다. 검색창을 누르면 이전 검색어를 다시 고를 수 있다.
- 0.5.2.0: 애셋 탭을 마우스 휠 클릭으로 닫을 수 있다.
- 0.5.1.0: 종료 전에 열어 둔 애셋이 다음 실행에서 다시 열린다.
- 0.5.0.0: 런처에 게임 썸네일이 보이게 했다. 이전에 연 게임이 있으면 다음 실행은 런처를 건너뛰고, 종료 전의 창 크기와 열어 둔 파일을 그대로 연다. 창 오른쪽 위의 버튼으로 런처를 다시 열 수 있다.
- 첫 화면에 프로그램 설명과 이 업데이트 기록을 두었다.
- 디버그 빌드에서 LibSaber를 게임 프로필 안에 넣어, 프로필이 그 파일을 따로 찾지 않아도 열리게 했다. F5로 앱을 빌드하고 실행한다.
- Warhammer 40,000: Space Marine 2를 열 수 있다. 4K 텍스처 팩, 더 빠른 리소스 목록, 메시 보정이 들어 있다.
- 모델을 glTF 2로 내보낼 수 있다. 모델 뷰포트와 텍스처 미리보기를 다듬고, Halo 2 Anniversary 프롭이 열리지 않던 문제를 고쳤다.
- 시작 화면을 넣고, 숫자 형식을 미국 영어로 고정해 소수점이 깨지지 않게 했다.
